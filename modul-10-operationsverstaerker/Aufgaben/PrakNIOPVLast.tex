\subsection{Analysis of a non-inverting amplifier with load\label{Aufg25}}
% Alt: Praktikumsaufgabe 11
\Aufgabe{
    Analyse the gain of a non-inverting operational amplifier and calculate the output voltage $U_\mathrm{A}$.
    Given:
    \begin{itemize}
        \item Supply voltage: $\pm 15\,\mathrm{V}$
        \item Input voltage: $U_\mathrm{E} = 1\,\mathrm{V}$
        \item Feedback resistance: $R_\mathrm{R} = 20\,\mathrm{k\Omega}$
        \item Input resistance: $R_\mathrm{E} = 10\,\mathrm{k\Omega}$
        \item Load resistance: $R_\mathrm{Last} = 10\,\mathrm{k\Omega}$
    \end{itemize}
    
    \begin{itemize}
        \item[a)] Calculate the output voltage $U_\mathrm{A}$ using the given values.  
        \item[b)] How does $U_\mathrm{A}$ change if $R_\mathrm{R}$ is increased to $30\,\mathrm{k\Omega}$?  
        \item[c)] What influence does the load resistor $R_\mathrm{Last}$ have on the output signal?

    \end{itemize}

\Loesung{
    \textbf{a) Calculation of the output voltage $\mathrm{U_A}$} \\
    Given are:
    \[
    U_\mathrm{E} = 1\,\mathrm{V}, \quad R_\mathrm{R} = 20\,\mathrm{k\Omega}, \quad R_\mathrm{E} = 10\,\mathrm{k\Omega}
    \]
    Insert into the amplification formula:
    \[
    V = 1 + \frac{20\,\mathrm{k\Omega}}{10\,\mathrm{k\Omega}} = 1 + 2 = 3
    \]
    The output voltage is calculated as follows:
    \[
    U_\mathrm{A} = V \cdot U_\mathrm{E} = 3 \cdot 1\,\mathrm{V} = 3\,\mathrm{V}
    \]

    \textbf{b) Change from $\mathrm{R_R}$} \\[0.2cm]
    If $R_\mathrm{R}$ is increased to $30\,\mathrm{k\Omega}$:
    \[
    V = 1 + \frac{30\,\mathrm{k\Omega}}{10\,\mathrm{k\Omega}} = 1 + 3 = 4
    \]
    \[
    U_\mathrm{A} = 4 \cdot 1\,\mathrm{V} = 4\,\mathrm{V}
    \]

    \textbf{c) Influence of load resistance} \\[0.2cm]
    The load resistance $R_\mathrm{Load}$ has only a minimal effect on the circuit as long as the operational amplifier is operating in the linear range.
    However, if the load resistance is too small, the operational amplifier may reach its output current limit, resulting in voltage limitation. \\
