\subsection{Investigation of a step-up converter for voltage boosting\label{Aufg28}}
% Alt: Praktikumsaufgabe 14
\Aufgabe{
    An upward converter can be used to convert small DC voltages (e.g. from a battery) into a higher DC voltage.
    Examine how an upward converter works by analysing the circuit.
    
    Gegeben:
    \begin{itemize}
        \item Input voltage: $U_\mathrm{E} = 1\,\mathrm{V}$
        \item inductance: $L = 900\,\mathrm{\mu H}$
        \item Diode: Ideal diode (no voltage drops taken into account)
        \item capacitor: $C = 470\,\mathrm{\mu F}$
        \item Switch: Opens and closes periodically
    \end{itemize}
    
    \begin{itemize}
        \item[a)] Explain how the step-up converter works in two phases:  
            \begin{itemize}
                \item \textit{Phase 1: Switch closed}
                \item \textit{Phase 2: Switch open}
            \end{itemize}
        \item[b)] Derive the formula for the output voltage $U_\mathrm{A}$ as a function of the duty cycle $D$:
            \[
            U_\mathrm{A} = \frac{U_\mathrm{E}}{1 - D}
            \]
        \item[c)] Calculate $U_\mathrm{A}$ for different duty cycles $D$:
            \begin{itemize}
                \item $D = 0{,}3$
                \item $D = 0{,}5$
                \item $D = 0{,}7$
            \end{itemize}
        \item[d)] What happens when $D$ approaches $1$? What practical limitations are there?
    \end{itemize}

\Loesung{
    \textbf{a) Explanation of how the step-up converter works} \\[0.2cm]
    The step-up converter operates in two phases:

    \begin{itemize}
        \item \textbf{Phase 1 (switch closed):}  
        The inductance $L$ is charged with current and stores energy in its magnetic field.  
        The diode blocks the current, so that no current flows to the output.
        
        \item \textbf{Phase 2 (switch open):}  
        The stored magnetic flux of the inductance collapses, causing the inductance to induce a voltage.  
        This voltage adds to the input voltage and charges the capacitor $C$ to a higher voltage.  
        The output now receives a higher voltage than the input voltage.
    \end{itemize}

    \textbf{b) Derivation of the output voltage formula} \\[0.2cm]
    In a steady state, the ratio between input and output voltage applies:
    \[
    U_\mathrm{A} = \frac{U_\mathrm{E}}{1 - D}
    \]
    where $D$ is the duty cycle (ratio of the time during which the switch is closed).

    \textbf{c) Calculation of the output voltage for different $D$} \\[0.2cm]
    Given is $U_\mathrm{E} = 1\,\mathrm{V}$.

    \begin{itemize}
        \item For $D = 0{,}3$:
        \[
        U_\mathrm{A} = \frac{1\,\mathrm{V}}{1 - 0{,}3} = \frac{1\,\mathrm{V}}{0{,}7} = 1{,}43\,\mathrm{V}
        \]
        \item For $D = 0{,}5$:
        \[
        U_\mathrm{A} = \frac{1\,\mathrm{V}}{1 - 0{,}5} = \frac{1\,\mathrm{V}}{0{,}5} = 2\,\mathrm{V}
        \]
        \item For $D = 0{,}7$:
        \[
        U_\mathrm{A} = \frac{1\,\mathrm{V}}{1 - 0{,}7} = \frac{1\,\mathrm{V}}{0{,}3} = 3{,}33\,\mathrm{V}
        \]
    \end{itemize}

    \textbf{d) Limits for $D \to 1$} \\[0.2cm]
    Theoretically, $U_\mathrm{A} \to \infty$ if $D$ approaches $1$.
    In practice, however, there are limitations due to:
    \begin{itemize}
        \item Inductance saturation
        \item Losses due to resistors, diodes and switches
        \item Limited switching frequencies
    \end{itemize}
    Typical values for $D$ are usually below 0.8 to ensure stable operation.
}
