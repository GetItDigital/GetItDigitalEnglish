\Loesung{

The given functional relationship between the output voltage $U_\mathrm{a}$ and the input voltages $U_1$ and $U_2$ is:
$
U_\mathrm{a} = -5 U_1 - 0,8 U_2
$

\textbf{1. Circuit description}

To implement this relationship, we use a summing circuit with an inverting operational amplifier. The output voltage of the inverting summing amplifier is:
$
U_\mathrm{a} = -\left( \frac{R_\mathrm{F}}{R_1} U_1 + \frac{R_\mathrm{F}}{R_2} U_2 \right)
$
Comparison with the target:
$
- \left( \frac{R_\mathrm{F}}{R_1} \right) = -5 \quad \Rightarrow \quad \frac{R_\mathrm{F}}{R_1} = 5
$
$
- \left( \frac{R_\mathrm{F}}{R_2} \right) = -0,8 \quad \Rightarrow \quad \frac{R_\mathrm{F}}{R_2} = 0,8
$

\textbf{2. Selection of resistance values}

We set $R_\mathrm{F} = 10\,\mathrm{k}\Omega$ (typical value in the range 1–100 k$\Omega$):
\begin{itemize}
    \item \textbf{Calculation of $R_1$}:
    $
    \frac{R_\mathrm{F}}{R_1} = 5 \quad \Rightarrow \quad R_1 = \frac{R_\mathrm{F}}{5} = \frac{10\,\mathrm{k}\Omega}{5} = 2\,\mathrm{k}\Omega
    $
    \item \textbf{Calculation of $R_2$}:
    $
    \frac{R_\mathrm{F}}{R_2} = 0,8 \quad \Rightarrow \quad R_2 = \frac{R_\mathrm{F}}{0,8} = \frac{10\,\mathrm{k}\Omega}{0,8} = 12,5\,\mathrm{k}\Omega
    $
\end{itemize}

\textbf{3. Implementation of the circuit}

The resistors used:
\begin{align*}
    R_\mathrm{F} &= 10\,\mathrm{k}\Omega \\
    R_1 &= 2\,\mathrm{k}\Omega \\
    R_2 &= 12,5\,\mathrm{k}\Omega
\end{align*}

\textbf{4. Circuit diagram of the implemented circuit}

The circuit consists of an operational amplifier whose inverting input is connected to resistors $R_1$ and $R_2$, which feed in input voltages $U_1$ and $U_2$. The non-inverting input is connected to ground.

\textbf{Summary:}

The desired functional equation $U_\mathrm{a} = -5 U_1 - 0.8 U_2$ is realised using the circuit described and the calculated resistance values.
